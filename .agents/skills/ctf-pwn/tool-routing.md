# Binary Exploitation Tool Routing

- pwntools: Primary framework for socket I/O, ELF parsing, and payload packaging.
- ropper / ROPgadget: Gadget search across static and dynamic binaries.
- checksec: Rapid mitigation verification.
- seccomp-tools: Dumping and analyzing BPF seccomp filters.
- pwndbg / GEF: Interactive GDB debugging for heap chunks and stack state.
